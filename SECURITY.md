# Security Policy

## Supported Versions

We actively support and patch the latest version of ExamArchitect.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not open a public GitHub issue**. Instead, report it securely:

1. **GitHub Security Advisory (Recommended):** Navigate to the **Security** tab of this repository on GitHub, click **Advisories**, and select **New draft security advisory** to report the vulnerability privately to the maintainers.
2. **Direct Contact:** If you prefer, email us at `security@examarchitect.com`.

We will acknowledge your report within 48 hours and provide a detailed timeline for investigation and patching.
